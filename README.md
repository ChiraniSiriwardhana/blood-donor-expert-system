# Blood Donor Eligibility Expert System (Prolog + Web UI)

An expert system written from scratch in **SWI-Prolog** that checks whether a person may donate blood, using the criteria of the **National Blood Transfusion Service (NBTS), Sri Lanka** (https://nbts.health.gov.lk/donate-blood/).
37 rules, 100+ facts, forward + backward chaining, explanation facility, web interface, 21 test cases + 21 explanation (proof tree) tests.
Educational prototype - the final decision is made by NBTS medical staff.

## Project structure
```
Blood_Donor_Eligibility_Expert_System/
├── README.md              this user manual
├── REFERENCES.md          sources of all knowledge
├── REPORT_CONTENT.md      report text + Annex A (all rules)
├── run_windows.bat / run.sh              start the system
├── run_tests_windows.bat / run_tests.sh  run the test cases
├── src/
│   ├── main.pl              entry point (starts the web server)
│   ├── knowledge_base.pl    facts + 37 rules (with sources)
│   ├── inference_engine.pl  forward + backward chaining
│   ├── explanation.pl       reasoning trace and proof tree
│   └── web_ui.pl            web interface (HTML generated by Prolog)
└── tests/
    └── test_expert_system.pl  21 test cases (expected vs actual) + 21 explanation tests
```

## 1. Requirements
- **SWI-Prolog 9.x** (free): https://www.swi-prolog.org/Download.html
- A web browser. No other dependency (the web server is built into SWI-Prolog).

## 2. Installation
- **Windows:** run the installer (Stable, 64-bit) and tick **"Add swipl to the system PATH"**; reopen Command Prompt. Check with `swipl --version`.
- **Ubuntu/Debian:** `sudo apt install swi-prolog`  |  **macOS:** `brew install swi-prolog`

## 3. Run
Open a terminal **in the project folder** (the one containing `src`) and run:
```
swipl src/main.pl
```
(Windows: double-click `run_windows.bat`; Linux/macOS: `./run.sh`.)
The browser opens automatically; otherwise open **http://localhost:8080**. Stop with **Ctrl+C** (twice).

## 4. How to use the web interface
1. Click **Start the check**.
2. Answer the questions one at a time (age, sex, weight, haemoglobin, previous donation, pregnancy, illness, epilepsy, risk behaviours, ID, foreign travel). Irrelevant questions are skipped; use **Back** to change an answer.
3. The **result page** shows the verdict (Eligible / Not eligible / Ask NBTS staff), the criteria checklist, reasons or recommendations, and **how the system reached the conclusion**: facts -> rules applied (forward chaining) -> backward-chaining proof tree.
4. **Knowledge Base** (`/rules`) lists all rules and sources; **Test Cases** (`/tests`) runs all 21 test cases and the 21 explanation tests live (each with its proof tree).

**Example input:** age 30, female, 48 kg, Hb 11.8, donated before (2 months ago), no illness/pregnancy/epilepsy/risk behaviour, has ID, travelled to India 12 months ago.
**Example output:** NOT eligible - rules d04 (interval), d05 (weight), d06 (haemoglobin), d11 (malaria travel) fired.

## 5. Run the tests (command line)
```
swipl -g run_all_tests -t halt tests/test_expert_system.pl
```
(Windows: `run_tests_windows.bat`; Linux/macOS: `./run_tests.sh`.)
Expected: `Passed 21 of 21 tests.` followed by `Explanation tests: passed 21 of 21.`
- Status tests only: `swipl -g run_tests -t halt tests/test_expert_system.pl`
- Explanation (backward-chaining proof) tests only: `swipl -g run_explain_tests -t halt tests/test_expert_system.pl`

## 6. Troubleshooting
| Problem | Fix |
|---|---|
| `swipl` is not recognised | Reinstall and tick "Add to PATH"; reopen the terminal |
| `source_sink ... does not exist` | You are in the wrong folder; `cd` into the folder that contains `src` |
| Port 8080 error | Close any other running copy of the program |
| Page does not load | Keep the terminal window open while using the browser |
| Permission denied for `run.sh` (Linux/macOS) | `chmod +x run.sh run_tests.sh`, or run `swipl src/main.pl` |
